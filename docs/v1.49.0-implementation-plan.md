## 2. M5 — 32-Bit Bit-Position Width (§10 OPT-D02)

**Target Files:**
- [`src/compress/decompressor50.hpp`](../src/compress/decompressor50.hpp)
- [`src/compress/decompressor50.cpp`](../src/compress/decompressor50.cpp)
- [`tests/unit/bitreader_stream_tests.cpp`](../tests/unit/bitreader_stream_tests.cpp)

### 2.1 Changes in `decompressor50.hpp`
- Change `BitReader` members:
  - `core::uint64 consumed_{0};`
  - `core::uint64 size_{0};`
  - `core::uint64 fetched_{0};`
- Change `BitReader` member functions:
  - `core::uint64 bit_pos() const { return consumed_; }`
  - `core::uint64 byte_pos() const { return consumed_ / 8; }`
  - `core::uint64 bits_remaining() const;`
- Update constructors:
  - `BitReader(const core::byte* data, size_t size);` (accepts size, converts to `core::uint64`)
  - `BitReader(InputCallback cb, core::uint64 size);`

### 2.2 Changes in `decompressor50.cpp`
- In `BitReader::bits_remaining()`:
  ```cpp
  core::uint64 BitReader::bits_remaining() const {
      core::uint64 rem_bytes = static_cast<core::uint64>(end_ - p_) + (size_ - fetched_);
      return rem_bytes * 8 + n_;
  }
  ```
- In `decompress_internal` (around lines 979-1020):
  - Change `size_t end_bit = block_end_bit(header);` to `core::uint64 end_bit = block_end_bit(header);`.
  - Change `auto cur_bit = [&]() -> core::uint64 { return reader.bit_pos(); };`.
  - Change `auto overran_block = [&](core::uint64 bit) { return header.block_size > 0 && bit > end_bit; };`.
  - Change `core::uint64 cb = cur_bit();`.
- In `decode_span` (around lines 1460-1476):
  - Change `size_t remain = expect.token_bits - reader.bit_pos();` to `core::uint64 remain = expect.token_bits - reader.bit_pos();`.
  - Change `const size_t end_bit = block_end_bit(header);` to `const core::uint64 end_bit = block_end_bit(header);`.

### 2.3 Unit Test in `tests/unit/bitreader_stream_tests.cpp`
Add boundary test verifying `bits_remaining()` on declared sizes $2^{29}-1$, $2^{29}$, and $2^{29}+1$ bytes without materializing input buffers:
```cpp
TEST_CASE("M5: BitReader 32-bit bit-position width boundary (OPT-D02)") {
    const core::uint64 SIZES[] = {
        (1ULL << 29) - 1ULL, // 536,870,911 bytes
        (1ULL << 29),        // 536,870,912 bytes
        (1ULL << 29) + 1ULL  // 536,870,913 bytes
    };
    for (core::uint64 sz : SIZES) {
        BitReader stream([](core::byte*, size_t) -> size_t { return 0; }, sz);
        CHECK(stream.bits_remaining() == sz * 8ULL);
    }
}
```

**Gate:** Unit test passes cleanly without memory allocation; builds with no narrowing warnings.

## 4. M1 & M2 — Streaming Archive Encode API & Hardening

**Target Files:**
- [`wasm/js/openrar-archive.js`](../wasm/js/openrar-archive.js)
- [`wasm/js/openrar-archive.d.ts`](../wasm/js/openrar-archive.d.ts)
- [`wasm/js/archive.test.mjs`](../wasm/js/archive.test.mjs)

### 4.1 Implementation of `createArchiveStream`
- Function signature:
  ```javascript
  export function createArchiveStream(files, opts = {})
  ```
- Accepts array, `Iterable`, or `AsyncIterable` of `CreateArchiveInput`.
- Constructs a `ReadableStream<Uint8Array>` with `[Symbol.asyncIterator]()`.
- In `start(controller)`:
  - Check `opts.signal?.aborted` upfront; if aborted, reject with `RarError('ABORTED', 'aborted', -11)` and call `controller.error(err)`.
  - Validate parameters (`method`, `windowLog2`).
  - Stream chunks incrementally (by file block or configured chunk size).
  - Use `safeRead` for chunk decoupling (host owns JS copy, engine memory freed immediately).
  - On error or OOM: map to `RarError('NOMEM', ..., -5)` if out of memory, unroll state, call `controller.error(err)` and NEVER `controller.close()`.
  - On clean completion: call `controller.close()`.

### 4.2 Test Suite Expansion
In [`wasm/js/archive.test.mjs`](../wasm/js/archive.test.mjs):
1. **Byte-Parity Test:** Concatenated chunks of `createArchiveStream(files, opts)` equal `await createArchive(files, opts)` byte-for-byte across multiple files, directories, and options.
2. **Fail-Closed Abort Test:** Pass an aborted `AbortSignal`; verify stream rejects and controller is errored (never cleanly closed).
3. **Fail-Closed Invalid Input Test:** Pass invalid method or illegal path; verify stream errors the controller.
4. **Chunk Ownership Test:** Verify that returned chunks are independent instances of `Uint8Array` detached from WASM memory.

**Gate:** All streaming tests pass; byte-parity verified; fail-closed behavior verified.
