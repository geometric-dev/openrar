# v1.25.0 Implementation Plan — Memory-Mapped Read Engine (Re-scoped)

**Status:** governing plan for the v1.25.0 arc. Normative inputs:
`docs/ROADMAP.md` §v1.25.0 (re-scoped) and `docs/SECURITY_ARCHITECTURE.md`
§5.2. There is no external pre-analysis for this arc; §0 records the scope
decisions against the roadmap text.

**Why this release exists:** listing and header-scanning an archive today
performs a seek+read syscall pair per header (per volume chunk). For
header-dense and multi-gigabyte archives that is the listing bottleneck.
The engine gains a memory-mapped read path for **listing, header-scanning
and random-read only** — extraction inputs stay buffered (SECURITY
ARCHITECTURE §5.2 is normative: POSIX files cannot be locked against
truncation, SIGBUS recovery is hostile to multithreaded engines).

## 0. Scope decisions

| Item | Verdict | Rationale |
| :--- | :--- | :--- |
| Mapped listing/header-scan | ADOPT | The whole scan becomes pointer arithmetic; zero data-area reads (both paths seek-skip data, mmap removes the header-read syscalls). |
| Mapped **extraction inputs** | REJECT (normative) | §5.2: never map extraction inputs. Extraction keeps buffered `ReadFile`/`read`. The mapped view and the extraction stream are separate handles. |
| Random-read surface | ADOPT | New C ABI read-region export served by the mapped view; falls back to buffered reads when mapping is unavailable. |
| Windows fault policy | ADOPT | SEH (`__try/__except` in a fault-guard leaf) → `RAR_ERR_IO`; the mapping is released and the caller falls back. |
| POSIX fault policy | ADOPT (re-scoped) | No signal handlers. Bounds-check every access against the map length; a pre-flight `fstat` records the mapped size; a size re-check before each bulk read enables the read fallback. Residual: a hostile concurrent truncation between size-check and access can still SIGBUS — documented, same posture as the roadmap text. |
| Limits on the mapped path | ADOPT | The mapped scan runs the SAME scan_archive code (limits enforced there); a test pins header-count/byte limits fire identically on the mapped path (limits-not-bypassable). |
| ABI | ADOPT | `OPENRAR_ABI_FEATURE_MMAP (1ull << 16)` + a read-region export; WASM surface unchanged except feature advertisement. |
| Scanner duplication | REJECT | No second scanner. `HeaderReader::read_block_raw` widens to a minimal `io::ReadSource` interface (`read/seek/tell/size`); `FileStream` implements it; the new mapped source implements it. Existing call sites compile unchanged. |
| Fail-open | ADOPT | If mapping fails (exotic filesystems, resource caps) the engine silently uses the buffered path — identical results, no error surfaced. |

## 1. Design

- `io::MappedFile` (new, `src/io/mapped_file.*`):
  - `open(path)` → open read-only, `fstat`/`GetFileSizeEx` pre-flight,
    map `[0, size)` (POSIX `mmap(PROT_READ, MAP_PRIVATE)`; Windows
    `CreateFileMappingW`+`MapViewOfFile`).
  - `read_at(off, dst, n)` → bounds-check against mapped length **and**
    a size re-check (`fstat`) — copy via the fault-guard leaf (Windows
    `__try`; POSIX plain `memcpy` after the bounds check).
  - `ReadSource` interface methods (`read/seek/tell/size`) so it can
    serve `read_block_raw` directly.
  - `close()`/RAII unmap.
- `io::ReadSource` (tiny abstract interface, `file_stream.hpp`):
  `size/seek/tell/read`. `FileStream` implements it (methods already
  exist); `HeaderReader::read_block_raw(io::FileStream&)` widens to
  `read_block_raw(io::ReadSource&)`.
- Scanner wiring: `ArchiveReader::open_ex` keeps its buffered behavior as
  the fallback; when mapped scanning is enabled (default on; CLI/engine
  opt-out) each volume file is opened as `MappedFile` first, and the
  existing `process_volume`/SFX-scan code runs against whichever source
  opened. `stream_` (buffered) remains the extraction input — unchanged.
- Random-read export: `openrar_archive_handle_read_entry_region(handle,
  entry_index, offset, length, out_buf)` — reads a byte range of an
  entry's stored payload; served from the mapped view when the mapped
  scan is active, else buffered; verifies CRC when the entry carries one
  and the range covers the whole payload? NO — partial ranges cannot be
  CRC-verified; the export reports which ranges are unverified via the
  return contract (documented; full-range reads verify).

## 2. Failure-Mode Matrix

Phases: M = map/open, S = mapped scan, R = random-read, F = fallback.
Classes: crafted archive, local attacker (truncation race), OOM/ENOSPC,
exotic filesystem, malformed headers.

| Phase \ Class | crafted archive | local attacker | OOM/ENOSPC | exotic FS | malformed |
| :--- | :--- | :--- | :--- | :--- | :--- |
| M | signature scan unchanged | pre-flight fstat bounds the map | open fails → buffered fallback | map fails → buffered fallback | n/a |
| S | same header validation as buffered | size re-check before bulk reads; shrink → read fallback / clean error | n/a | n/a | identical verdicts to buffered (same code) |
| R | CRC-verified when full payload range requested | truncation → graceful RAR_ERR_IO (SEH/bounds) | n/a | buffered fallback | offsets clamped/bounds-checked |
| F | byte-identical results to mapped path | n/a | n/a | this IS the fallback | n/a |

## 3. Named Negative Tests

1. `truncation_after_map_read_fails_gracefully` — map a file, shrink it,
   read past the new EOF → clean failure (SEH on Windows, bounds on
   POSIX), never a crash.
2. `truncation_mid_scan_falls_back` — shrink the archive between
   volumes → scanner reports a clean truncated-archive verdict, no
   signal.
3. `limits_enforced_on_mapped_path` — `max_header_count`/`max_header_bytes`
   abort identically on the mapped path (limits-not-bypassable).
4. `extraction_bytes_identical_mapped_vs_buffered` — extract with and
   without the mapped scan; payload bytes identical (extraction never
   takes the mapped path).
5. `mmap_unavailable_falls_back` — mapping forced to fail → buffered
   results identical.
6. `abi_feature_bit_mmap_reported` — `openrar_abi_features()` bit 16 set;
   read-region export present.
7. `read_region_out_of_range_rejected` — offset/length beyond the entry
   payload rejected; full-range read CRC-verified when a checksum exists.

- **M3** — C ABI feature bit + random-read region export + tests.
- **M4** — 50 GB listing benchmark + CI step.
- Release — CHANGELOG, stamp 1.25.0 (MINOR; counter resets, anchor moves

before the next begins.
