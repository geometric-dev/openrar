3. **Sandboxed worker (M3 — prereq 2, directives 2–6, 8).** New
   `src/sandbox/` at layer rank 5 (beside cli; cli→sandbox and
   sandbox→archive both legal — layer_check `LAYER_RANK` +
   ARCHITECTURE.md §2/§6 updated in the same change).
   - **Trust boundary (Gate 0 cleared):** the broker (host process)
     owns every filesystem handle, derives keys, enforces
     ExtractionLimits/cumulative caps/timeouts, performs ALL writes
     through the unchanged v1.24 ExtractionSession/AtomicWriter
     containment machinery, applies metadata policy, renders all
     output. The worker receives ONLY: inherited read-only volume fds
     (never a path it could open), its IPC channels, and derived key
     material where encrypted (raw passwords NEVER cross; residual:
     derived keys in worker memory, zeroized post-use, documented). It
     parses headers, decodes, verifies CRC/BLAKE2sp, streams decoded
     bytes and structured results back. It cannot open/write/rename
     files, exec/fork, or touch the network. Worker is UNTRUSTED at the
     IPC: the broker validates every frame (bounded length ≤ 4 MiB,
     bounded counts, cumulative byte cap) and re-runs all policy; the
     frame parser is written to parser-grade standards.
   - **Channel abstraction (directive 2):** two one-way framed channels
     (worker←broker commands, worker→broker results) over POSIX
     socketpairs / Windows dual anonymous inheritable pipes (Winsock
     sockets do NOT inherit like kernel handles — named now, not in
     M3). Multi-volume: all volume fds pre-passed at OPEN (fd-set bound
     documented); a missing volume is a broker-side OPEN failure — no
     mid-scan fd requests in v1.30.0.
   - **IPC protocol (versioned):** `u32 length (≤ 4 MiB) | u8 type |
     payload`; types OPEN{fd count}, KDF_PARAMS{salt,lg2,pswcheck},
     KEY{derived material}, SCAN_RESULT{packed entries}, EXTRACT_REQ,
     DATA_CHUNK, ENTRY_RESULT, ERROR{code,detail} (codes are the shared
     RarError values — §3.1, no new namespace), CANCEL, PING/SHUTDOWN.
     **Key protocol (directive 4):** worker → `KDF_PARAMS` on
     `HEAD_CRYPT` → broker derives (PBKDF2, ceilings enforced
     broker-side too) → `KEY` → worker continues (headers stay opaque
     until the key arrives); per-file salts/IVs ride header parse.
   - **Per-OS models:** Windows AppContainer/LPAC (empty capability
     list, `PROC_THREAD_ATTRIBUTE_SECURITY_CAPABILITIES`, inherited
     handles, v1.23 Job-Object caps as defense-in-depth; `<windows.h>`
     at global scope only — the msvc-arm64 trap); Linux
     `PR_SET_NO_NEW_PRIVS` + seccomp-BPF allowlist AS DATA — including
     the memory-management family `brk`/`mmap`/`mprotect`/`munmap`/
     `madvise` (without them malloc cannot serve the dictionary window
     and a CORRECT sandbox kills the worker) with `PROT_EXEC`
     argument-filter stance stated — plus `read/write/pread64/futex/
     rt_sig*/exit_group`; worker declared SINGLE-THREADED (no `clone`;
     a future threaded worker is a documented allowlist change, never an
     accident); `CLONE_NEWUSER|CLONE_NEWNS` as probe-then-skip extra
     hardening (Ubuntu 24.04 AppArmor restricts unprivileged userns —
     never load-bearing). macOS Seatbelt (`sandbox_init`, deprecation
     status documented): deny-default profile, no `file-write*`, no
     `network*`, no `process-*`; per-model mediation notes (what
     Seatbelt does/does not mediate on inherited fds) recorded in the
     module from MEASURED behavior, not folklore.
   - **Mode selection (directive 1):** ONE decision function,
     `sandbox_mode_for(scope)` → {worker, in_proc}, consumed by every
     command path (`x`/`e`/`t`/`p`/`l*`); inputs: `--in-proc` flag,
     `OPENRAR_IN_PROC` env (the `--no-mmap`/`OPENRAR_NO_MMAP`
     kill-switch pattern), platform model availability probe. Default
     = worker where available. Spawn failure → LOUD fallback: ONE
     `W:` notice per run (never per-file), machine-readable
     `sandbox_active:false` in `--json-summary`, in-process run
     continues (exit taxonomy unchanged). `a`/mutation/creation/SFX
     stay in-process (the writer path is not the §5.1 parser surface).
     WASM unaffected (no processes); DLL unaffected (in-process by
     contract — §7.3 embedders self-sandbox; a sandboxed DLL family
     would take feature bit 17 post-2.0, no speculative reservation).
   - **Frame stability (directive 8):** worker scan order IS the entry
     index space everywhere (listing, extract indices, JSON summary) —
     conversions confined to the IPC boundary; byte counts: worker
     reports per-entry decoded totals, broker counts received bytes —
     never mixed. Progress coalesced to the ≤30 ms tick model
     (progress rides ENTRY_RESULT/DATA_CHUNK metadata, not per-chunk
     callbacks); reusable staging buffers per direction on the hot
     path (no per-chunk heap churn). One worker per archive (or per
     parallel slot), never per entry.
   - **Parallel pool:** slot workers each get the fd set + channels;
     solid chains and phase-2/3 machinery unchanged. If the pool
     exceeds its budget: documented degradation = sandboxed mode runs
     the sequential engine, parallel auto-falls-back in-process with
     the loud notice (kill signal, pre-analysis §3).

## 2. Constraints & interactions (directive 1: engine trace + decision function)

**Single decision function:** `sandbox_mode_for(scope)` — the ONLY
selector of worker vs in-process; every command path consumes it; the
`--in-proc` flag and `OPENRAR_IN_PROC` env feed it; no path may branch
on its own spawn attempts.

| Engine / site | Mode honored | Progress path | Cancel path | Limits path |
| :--- | :--- | :--- | :--- | :--- |
| sequential `x`/`e` (worker) | sandbox_mode_for | ENTRY_RESULT/DATA_CHUNK → tick model (≤30 ms) | CANCEL frame → RAR_ERR_ABORTED (255 via §3.1) | broker enforces on received bytes + worker-side caps |
| parallel pool slots (worker) | sandbox_mode_for (pool may degrade per §1.3) | per-slot ENTRY_RESULT → existing note_file_done | CANCEL frame per slot | broker cumulative caps unchanged |
| sequential/parallel (in-proc fallback) | in_proc — EXISTING behavior byte-identical | v1.28 reader hooks | v1.28 hooks | v1.24 caps |
| `t`/`p`/`l*` | sandbox_mode_for (worker: no disk writes; test verdicts via ENTRY_RESULT) | tick model | CANCEL frame | broker caps |
| `a`/mutation/`rr`/`sfx`/creation | in_proc ALWAYS (writer path) | unchanged | unchanged | unchanged |
| WASM | N/A (no processes; kill-switch meaningless) | unchanged | unchanged | unchanged |
| DLL | N/A (in-process by contract) | unchanged | unchanged | unchanged |

- **Exit taxonomy:** no new codes (§3.1); worker failures map to pinned
  codes at the broker; cancel stays 255; fallback is a warning, not an
  exit-code change.
- **Zero-format:** nothing in M1–M7 touches `src/format/` or writer
  emission; sandbox changes WHO reads/writes bytes, not what bytes are.
- **Timestamps/encryption/solid/-cdc/-oi/-v:** behavior preserved — the
  worker runs the same engines; metadata policy stays broker-side;
  clamps/caps feed the same report + JSON flags.
- **layer_check:** `src/sandbox` joins rank 5; LAYER_RANK +
  ARCHITECTURE.md §2 same change; run locally before every push.
- **Version-consistency gate:** untouched until the release commit
  (CMakeLists + wasm/js/package.json BOTH to 1.30.0 post-rebase).

Phases: BW = broker/worker IPC, SD = sandbox denial, LM = library-mode
embedder, SDK = binding, SC = supply-chain pipeline. Classes: crafted
input / privilege boundary / IPC failure-crash / platform (3 OS models)
/ tampering.

| Phase \ Class | crafted input | privilege boundary | IPC failure/crash | platform | tampering |
| :--- | :--- | :--- | :--- | :--- | :--- |
| BW | frame parser is parser-grade: hostile frames (overlong, truncated, bad type, oversized) → abort, no UB (`sandbox_ipc_malformed_frame_rejected`); worker-emitted bytes pass broker caps + downstream CRC | broker re-runs ALL policy on worker reports; worker cannot widen privileges (no fds beyond OPEN, no paths, no exec) | worker crash/kill −9 → socket EOF → clean broker error, no partial dest, journal sweep exact (`sandbox_worker_crash_isolation`); broker crash → worker exits on EOF, no orphan writes | spawn unsupported → LOUD in-proc fallback (once-per-run `W:` + `sandbox_active:false`); AppContainer/LPAC, userns/AppArmor, Seatbelt deprecation all probe-then-skip | compromised worker: bounded frames, cumulative caps, no filesystem reach; output garbage caught by CRC/BLAKE2sp downstream |
