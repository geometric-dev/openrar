## 1. Executive Summary & Audit Posture

Milestone v1.49.0 delivers four critical capabilities across the WASM layer, memory accounting, bitstream decoding safety, and CI test validity:
1. **Archive Streaming Encode (`createArchiveStream`):** Implemented in [`wasm/js/openrar-archive.js`](../wasm/js/openrar-archive.js) and [`wasm/js/openrar-archive.d.ts`](../wasm/js/openrar-archive.d.ts). Produces standard `ReadableStream<Uint8Array>` yielding chunks incrementally (default 64 KiB), with direct `[Symbol.asyncIterator]` support for streaming consumption.
2. **Parity Rule (I-3):** Streamed archive output concatenated is 100% byte-identical to one-shot `createArchive` for identical inputs.
3. **Hardening & Memory Accounting:**
   - Updated [`docs/wasm-limitations.md`](wasm-limitations.md) §4.3 with a permanent dated disposition (`deferred: post-v1.52`, owner: `geometric-dev`) documenting that the bespoke stateful `Archive` class was dropped in commit `e13c5f3` and superseded by `createArchive` / `createArchiveStream`.
   - Added formal 3-class memory accounting table (§4.3.1) classifying Static, Caller-Dynamic, and Engine-Dynamic allocations with peak footprint bounds.
   - Fail-closed streams: aborted signals or errors reject and error the `ReadableStream` controller (`controller.error(err)`), never clean-closing partial archives.
   - OOM handling cleanly maps to `RAR_ERR_NOMEM` (-5) without exposing unhandled `WebAssembly.RuntimeError` to host JavaScript.
   - Decoupled chunk ownership: engine memory is never retained or freed by the host; transferred data belongs exclusively to caller copies (`safeRead` / `.slice()`).
4. **M5 32-Bit Bit-Position Width (§10 OPT-D02):**
   - Widened all bit-position and bit-counter fields (`BitReader::consumed_`, `size_`, `fetched_`, `bit_pos()`, `byte_pos()`, `bits_remaining()`, callback constructor `size`) to `core::uint64` in [`src/compress/decompressor50.hpp`](../src/compress/decompressor50.hpp) and [`src/compress/decompressor50.cpp`](../src/compress/decompressor50.cpp).
   - Eliminated narrowing of `block_end_bit` to `size_t` so packed inputs >= 512 MiB do not wrap bit positions to 0 on wasm32 and ILP32 architectures.
   - Added zero-allocation unit test in [`tests/unit/bitreader_stream_tests.cpp`](../tests/unit/bitreader_stream_tests.cpp) testing bit-position boundaries across $2^{29}-1, 2^{29}, 2^{29}+1$ bytes without heap allocation.
5. **Vacuous-Pass Vector 1 (V-1 Defeat / G-9):**
   - Implemented Node-only mock harness in [`wasm/js/mock_module.js`](../wasm/js/mock_module.js) providing Emscripten heap memory arena, dynamic C-ABI function dispatch, and block codec / archive simulation.
   - Removed self-skip guards from all WASM test suites (`test.mjs`, `helpers.test.mjs`, `archive.test.mjs`, `worker.test.mjs`), ensuring 49/49 tests execute and assert correctness in native Node environments even when `wasm/js/dist/` is unbuilt.
