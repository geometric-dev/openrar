## 1. Overview & Architectural Objectives

The v1.47 milestone delivers four core platform security and robustness deliverables:
1. **OPT-F01 (WAV Delta Audio Detection UB Fix):** Eliminate integer truncation and 32-bit arithmetic overflow in `Filters50::detect_filter` (`filters50.cpp:140`).
2. **M0 & M0b (macOS Seatbelt Platform Confinement):** Implement Apple Seatbelt isolation profile (`sandbox_init` / SBPL) in `spawn.cpp` with honest capability-gap reporting and loud disclosure on fallback.
3. **M1 & M2 (Foreign-Format Fuzz Targets):** Implement `fuzz_zip` and `fuzz_tar` targeting parser discrepancies, ZIP64/PAX edge conditions, and structural attack surfaces.
4. **M3 (TSan Parallel Decode Concurrency Hardening):** Validate thread handoffs and span processing in `parallel_decode.cpp` under ThreadSanitizer.

## 2. Proposed Changes & Implementation Phases

### Phase 1: WAV Audio Detection UB Fix (OPT-F01 / M5)
- **Target File:** [`src/compress/filters50.cpp`](../src/compress/filters50.cpp#L138-L146)
- **Changes:**
  - Widen stride computation to 32-bit unsigned integers:
    ```cpp
    const core::uint32 ch = core::read_le16(data + 22);
    const core::uint32 bps = core::read_le16(data + 34);
    const core::uint32 total_bits = ch * bps;
    const core::uint32 stride = total_bits / 8;
    if ((total_bits % 8 == 0) && stride >= 1 && stride <= 32) {
        out_channels = static_cast<core::uint8>(stride);
        return FilterType::Delta;
    }
    ```
  - Verify that legitimate WAV streams (1..8 channels, 8/16/24/32 bps, stride <= 32) continue to be detected cleanly.
  - Verify that truncated cases (e.g. `ch=2, bps=1032`) and overflow cases (`ch=0xFFFF, bps=0xFFFF`) return `FilterType::None`.

### Phase 2: macOS Seatbelt Sandboxing (M0 / M0b)
- **Target Files:**
  - [`src/sandbox/spawn.cpp`](../src/sandbox/spawn.cpp#L380-L435)
  - [`src/sandbox/sandbox_mode.cpp`](../src/sandbox/sandbox_mode.cpp)
  - [`src/sandbox/spawn.hpp`](../src/sandbox/spawn.hpp)
  - [`src/sandbox/worker_main.cpp`](../src/sandbox/worker_main.cpp)
- **Changes:**
  - Under `#ifdef __APPLE__`, implement `platform_sandbox_available()` checking for macOS Seatbelt support (`sandbox_init` in `<sandbox.h>`).
  - Implement macOS Seatbelt profile in `spawn_worker_process`:
    ```scheme
    (version 1)
    (deny default)
    (allow file-read* (subpath "/usr/lib") (subpath "/System/Library") (subpath "/dev/urandom"))
    (deny file-write*)
    (deny network*)
    (deny process-fork)
    (deny process-exec)
    ```
  - Implement worker executable resolution via `_NSGetExecutablePath` (`<mach-o/dyld.h>`).
  - Wire fallback warnings to notify users when sandbox containment is unavailable.

### Phase 3: Foreign-Format Fuzzers (M1 / M2)
- **Target Files:**
  - `tests/fuzz/fuzz_zip.cpp` (new)
  - `tests/fuzz/fuzz_tar.cpp` (new)

- **Changes:**
  - `fuzz_zip.cpp`: feed mutated streams into `ForeignZipReader`, asserting exit-code oracle consistency (CD-vs-LFH discrepancies trigger refusal without crash or memory leak).
  - `fuzz_tar.cpp`: feed mutated streams into `ForeignTarReader`, asserting memory bounds against hostile PAX and GNU LongLink headers.

1. **Compilation:** Clean build on MSVC, GCC, and Clang with warnings-as-errors (`/W4 /WX`, `-Wall -Wextra -Werror`).
2. **Audio Filter Parity:** Valid audio WAV inputs produce byte-identical archives; malformed WAV inputs reject delta filter application without crashing.
3. **Foreign Format Integrity:** `fuzz_zip` and `fuzz_tar` run cleanly without leaks or uncontrolled crashes.
4. **Test Suite:** 100% CTest tests pass. Verification ledger updated and anchor lint clean (0 violations).
