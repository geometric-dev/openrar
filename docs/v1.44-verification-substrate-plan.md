## 2. M0 — JUnit + `--test-case` + per-case timing (hygiene-first)

### 2.1 The runner (`tests/support/test_runner.{hpp,cpp}`, in-repo, zero deps)
One shared runner TU compiled into every test target. Per-file `main()` becomes a thin entry that (a) runs its prehook, then (b) delegates to the runner with a **static case table** built from the existing `test_xxx()` functions — no assert touched, no include added:

```cpp
// before:  int main(){ test_cli_help(); test_cli_version(); ... }
// after:   static const openrar::test::Case k_cases[] = {
//              OPENRAR_CASE(test_cli_help), OPENRAR_CASE(test_cli_version), ... };
//          int main(int argc, char** argv) { return openrar::test::run(k_cases, argc, argv); }
```

Runner contract (CLI uses **doctest's flag names** so the M1 harness treats pre/post binaries identically and M4/M5 migration changes zero CLI consumers):

| Flag | Behavior |
|---|---|
| `--test-case=<glob>[,<glob>…]` | run only matching cases (fn-name-based case name; `*` wildcard) |
| `--list-test-cases` | print registered names (machine table), exit 0 |
| `--out=<file>` / alias `--junit=<file>` | JUnit-schema XML (per-case entries, times, failures) |
| (none) | full suite in source order |

Behaviors: per-case `[PASS]/<name>` lines retained + one `[RUNNER]` summary block per case (`[RUNNER] case="<name>" result=pass|fail|skip time=<ms>`) for the M1 harness; **stdout flushed before each case starts** so an `assert` abort leaves the previous cases' statuses visible; abort in a case = that case fail + later cases skip, exit non-zero (ctest semantics preserved); unknown flag = hard error; **G-9 no-vacuous-pass:** exit non-zero if a filter matched nothing, if a requested case never executed, or if zero cases ran; per-case timing via `std::chrono::steady_clock`.
The runner owns the `_MSC_VER` assert-routing block (centralizes the duplicated inline copies; `test_support.hpp` macro stays for non-runner users).

### 2.2 Wiring
- `add_openrar_test` targets: append the runner TU (single line change in CMake function).
- Hand-rolled twins (§1 table row 5): append the same TU to each `add_executable`.
- The 4 argv suites: prehook-first shape — the file parses/handles its own reserved argv (`--crash-hook-test=`, SFX stub semantics) and delegates the rest; unknown-args handling is per-file by explicit hook, not global.

### 2.3 CI JUnit (CMake-3.16-safe)
`tools/ctest_to_junit.py` converts `build/Testing/Temporary/LastTest.log` (written by every ctest run, suite-level `<testsuite>` entries incl. times/outputs) → single `junit.xml`; **asserts executed** (G-9): suite count ≥ expected floor, no empty testsuites, premature-exit suites marked failed. `build.yml` test steps append the invocation (this is additive plumbing; no existing assertion relaxes). Artifact: `upload-artifact@v4` of `junit.xml` (CI-side convenience; not a test runtime dep).

### 2.4 M0 gates
- **Wrap batching:** smallest→largest file; full `ctest` sweep green between batches; compress_tests still wrapped last; per-batch case-table count audited against the main-body call list (1:1, order preserved — no re-sorting ever).
- Full `ctest` sweep green, rc/output conventions unchanged.
- Per-suite `--list-test-cases` totals = the hand-assembled case lists (spot-audit table in the arc roadmap entry).
- `junit.xml` produced on CI and locally via the aggregator + at least one binary-level `--junit=` demo.
- Ledger unchanged: 3,701 asserts (no rewrites spin in M0).

## 9. Substrate FFM + Negative-Test Plan (architect-challenge directives, incorporated 2026-10-18)

**FFM for new code paths (runner / JUnit writer / aggregator):**

| Path | Failure | Response |
|---|---|---|
| Runner dispatch | case aborts mid-run | completed cases pass, aborting case fail, later = skip; rc non-zero; stdout flushed pre-case |
| Runner dispatch | `--test-case` matches nothing | **exit non-zero (G-9)** |
| Runner dispatch | duplicate case name | registration-time hard error (fail-closed) |
| Runner dispatch | non-ASCII case name | registration-time hard error; grammar `[A-Za-z0-9_.-]+` |
| Runner dispatch | unknown flag | hard error, no dispatch |
| Runner dispatch | argv-prehook suite leaks reserved flags | prehook handles before runner; runner hard-errors on its own unknown flag namespace only |
| Runner dispatch | expected-fail marker case aborts | recorded expected, harness-visible (FMM-44 `WILL_FAIL` expressibility preserved; wiring deferred to that suite's arrival arc) |
| JUnit writer | abort mid-suite | elements streamed to temp sibling; footer only on clean completion; **real path never written**; orphan temp remains |
| JUnit writer | partial write / crash | real path absent (atomic rename only on valid completion) |
| Aggregator | missing/garbled LastTest.log | **hard error — never emits empty-but-green XML** |
| Aggregator | suite absent from log / `Not Run` | mapped to failed testcase; suite-count floor from CMake registration data |
| Aggregator | unknown future format fields | asserted-fields parse (not free-form grep); unknown = error |

**Named negative tests** (new suite `tests/unit/runner_tests.cpp`, wrapped like everything else):
`runner_filter_no_match_fails` · `runner_duplicate_name_rejected` · `runner_unknown_flag_rejected` ·
`runner_list_format_stable` · `runner_abort_reports_completed_partial_fail` (marker case asserts deliberately
under the runner; suite observed as fail) · `runner_junit_atomic_rename_no_partial` · `aggregator_failclosed_garbled_log`.

**Uplifted contracts from the challenge:** exit codes = {0,1} only, abort statuses pass through untouched; case
grammar `[A-Za-z0-9_.-]+`, source-order execution only, globs limited to `*` (doctest's richer patterns wait for
harness support); unit-success banners print only after a full unfiltered rc==0 run (headers pre-dispatch, unchanged);
JUnit = streaming temp sibling + atomic rename (no cross-volume rename); M4 doctest pin recorded with exact version +
SHA-256 and the `/EHsc` exceptions requirement asserted; M1 harness runs per-file locally (parent-commit pre-binary)
with one full-tree harness run at tag pre-flight, never CI-per-file.

- R6 JUnit aggregation from LastTest.log is suite-granular only (per-case XML stays local to each binary); stated, not hidden.
