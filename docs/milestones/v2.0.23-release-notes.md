# OpenRAR v2.0.23 Release Notes: Decompression Bomb Hardening, Bounded C ABI & Toolchain Hardening

**Release Tag:** `v2.0.23`  
**Anchor Tag:** `v2.0.0`  
**Governance Scope:** Invariant I-1 (Bounded Allocations), I-2 (Bitstream Determinism), Frozen C ABI LTS, and `architect-walkthrough` sign-off  
**Status:** ✅ Complete, Hardened & Verified  

---

## 1. Executive Summary & Deliverables

OpenRAR `v2.0.23` is a major security, stability, and hardening release for the v2.0 LTS line. It addresses critical adversarial review findings across core compression engines, closes decompression-bomb denial-of-service vulnerabilities, expands public C exports with bounded extraction limits, and enforces hardened toolchain security and deep static analysis across the entire codebase.

### Primary Achievements

1. **Decompression Bomb Protection & Hard Output Ceilings (Findings F1, P0-1, P0-2):**
   - Enforced `DEFAULT_STREAM_CAP` (512 MiB on 64-bit native / 128 MiB on 32-bit/WASM) across all unbounded `decompress_to_vector` and `StreamDecoder` calls.
   - Thwarts amplification attacks exploiting Huffman Slot 257 run-continuation (1 bit → 4100 bytes).
   - Added `HARD_MEMBER_CAP` (512 MiB native / 128 MiB 32-bit/WASM) and multi-entry cumulative ceiling (16 GiB native / 2 GiB 32-bit/WASM) in `BufferArchive::extract`.

2. **Bounded Public C ABI & Streaming File Extraction:**
   - Introduced `openrar_archive_extract_to_buffer_bounded`, `openrar_archive_extract_to_file_bounded`, and `openrar_decompress_buffer_bounded` accepting caller-specified `RarExtractionLimits`.
   - Advertised via new feature bit 19: `OPENRAR_ABI_FEATURE_STATELESS_LIMITS`.
   - Added direct-to-disk streaming file extraction with atomic rollback and automatic unlinking on limit breach.

3. **Parallel Timeline & Prescan Memory Budgeting (Finding F2):**
   - Deduplicated identical Huffman table descriptions across block boundaries in `prescan_member`, capped by `PRESCAN_MAX_DESCRIPTIONS` (4096), preventing memory amplification from adversarial 3-byte block headers.
   - Wrapped parallel decode execution in `std::bad_alloc` handlers with graceful fallback to sequential decoding.

4. **Static Analysis & Compiler/Library Security Hardening:**
   - Expanded `.clang-tidy` to enforce `bugprone-*`, `cert-*`, `clang-analyzer-*`, `performance-*`, and `misc-*` checks while maintaining strict naming enforcement.
   - Audited and remediated all 70 source files in `src/` to achieve 0 static analysis diagnostics.
   - Introduced `OPENRAR_HARDENED` option (enabled by default on native builds):
     - **MSVC**: `/GS`, `/EHsc`, Control Flow Guard (`/guard:cf`), `/DYNAMICBASE`, `/NXCOMPAT`, `/HIGHENTROPYVA`, and `/CETCOMPAT` (Intel CET on x64).
     - **GCC / Clang**: `-D_GLIBCXX_ASSERTIONS`, `-D_LIBCPP_HARDENING_MODE=_LIBCPP_HARDENING_MODE_FAST`, `-D_FORTIFY_SOURCE=3` (Release), `-fstack-protector-strong`, `-fstack-clash-protection`, `-fcf-protection=full` (x86_64), `-mbranch-protection=standard` (AArch64), full RELRO, and `noexecstack`.

5. **Bitstream & Concurrency Defect Remediation:**
   - **CDC Data Race (P1-02):** Replaced bit-packed `std::vector<bool>` with byte-addressed `std::vector<uint8_t>` in multi-threaded CDC slice workers.
   - **Checksum Bypass (P1-01):** Enforced mandatory decompression and checksum computation in `test_entry` even when headers omit `FHFL_CRC32`.
   - **Inflate RFC 1951 Parity (F3):** Accepted valid single-code dynamic distance and literal/length tables.
   - **ILP32 / 32-bit Integer Wraps (P0-3, F4):** Bounded window-sizing bit shifts in `compress_buffer` and widened distance arithmetic to 64-bit in `apply_span_records`.
   - **Large Window Horizon (P1-1):** Promoted match distance tracking from `uint32_t` to `size_t` in Forward-Arrival lookahead graphs.

6. **Cloud Benchmark Infrastructure:**
   - Added `--submit` flag to `openrar b` for real-time benchmark submission to `https://benchmark.openrar.workers.dev/submit`.
   - Built-in dynamic markdown leaderboard generator with full anonymization (submitter identities purged).

## 2. Security Findings & Remediations Matrix

| ID | Module | Vulnerability / Issue | Severity | Remediation |
|---|---|---|---|---|
| **F1** | `decompressor50.cpp` | Unbounded `decompress_to_vector` default cap (64 GiB) vulnerable to Slot 257 amplification | **P0** | Enforced `DEFAULT_STREAM_CAP` (512 MiB / 128 MiB) on unbounded calls |
| **P0-1** | `buffer_archive.cpp` | `BufferArchive::extract` unbounded allocation on hostile declared unpacked size | **P0** | Enforced `HARD_MEMBER_CAP` before vector reservation and during write loop |
| **P0-2** | `buffer_archive.cpp` | Cumulative extraction across entries unbounded in stateless extraction | **P0** | Clamped cumulative output to 16 GiB (2 GiB on 32-bit/WASM) |
| **P0-3** | `compressor50.cpp` | Non-terminating window-sizing loop under ILP32 when shift exceeds word size | **P0** | Added `shift < 30` loop bound guard |
| **F2** | `decompressor50.cpp` | Unbounded Huffman table description allocation in `prescan_member` | **P1** | Table deduplication + `PRESCAN_MAX_DESCRIPTIONS` (4096) cap + `bad_alloc` catch |
| **P1-01** | `archive_reader.cpp` | Corrupted payloads bypass `test_entry` when `FHFL_CRC32` is cleared | **P1** | Enforce decoding and verify unpacked size when checksum absent |
| **P1-02** | `cdc_chunker.cpp` | Data race on `std::vector<bool>` bit storage in concurrent slice workers | **P1** | Converted to byte-addressed `std::vector<uint8_t>` |
| **P1-1** | `compressor50.hpp` | `ArrivalNode::token_dist` 32-bit truncation for dictionaries > 4 GiB | **P1** | Promoted `token_dist` and `dist` fields to `size_t` |
| **P1-2** | `archive_reader.cpp` | Empty-data member declaring non-zero size passed silently | **P1** | Explicit check rejecting empty payload with `RAR_ERR_TRUNCATED` |
| **P1-3** | `archive_reader.cpp` | Stored method 0 unpacked size not verified against declared `unp_size` | **P1** | Verified stored unpacked size matches header `unp_size` |
| **P1-4** | `archive_reader.cpp` | SFX candidate probe copies full block before validating header type | **P1** | O(1) header type inspection before copy or CRC computation |
| **F3** | `inflate.cpp` | Rejection of legal RFC 1951 §3.2.7 single-code distance/literal trees | **P2** | Accepted single-code trees with 1-bit dummy codes per RFC 1951 / zlib |
| **F4** | `parallel_decode.cpp`| 32-bit unsigned offset arithmetic wrap in `apply_span_records` | **P2** | Widened distance to 64-bit prior to `+1` increment |
| **F6** | `dll_api.cpp` | Unbounded archive comment decoding and 32-bit integer truncation | **P2** | Bound comment decode to `MAX_COMMENT_PAYLOAD` with checked bounds |
